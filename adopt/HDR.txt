COMMUNICATION RULE (ICOM v2, codebook 1.16.0, rule 12 strict; supersedes older summary rules below): agent-to-agent msgs = ICOM header @FROM>ICOM>TO P0-3 CLIENT #ticket VERB object + key=val tokens, ending cb=1.16.0 icom=v2 ts=<AZ>, max 1 line per item. CLIENT is a codebook client code, INT0 if none. Never write the word LANE. Banned to agents: TL;DR sentences, prose, articles, numbered explanations, quotes (use f=path). Only the lead agent (code LDR in this public codebook) speaks English to the owner (human, code HUM). Client-facing mail/SMS/voice unchanged. ICOM NAKs non-compliant msgs. Spec: PROTOCOL-v1.md rules 11-12. SAY is not a verb.
RULE 12a: English only for msgs to the owner (human), clients and external humans. All else incl own chat display text = ICOM format. English otherwise only if the owner asks.
RULE 14: header object = ICX concept code (github.com/rstan251/icx), coarse to fine, e.g. pr.voice.intake~cfg. Client stays in the CLIENT slot (INT0 if none). Unknown concept = x.<word>. First word is a class: org pr sys ops mk fin lg rs dt x.
RULE 24 NO-ECHO (formerly rule 18): never answer DONE/FYI/ACK/REC with another DONE/FYI/ACK/REC on the same ticket. Only GO/ASK/DECIDE/BLOCKED/NAK/HOLD or a real state change may follow. One DONE per ticket per SoR state change. After a pause or cap, keep the first quiet line per ticket (a reset verb starts a new group), drop later quiets, and do not reply to stale ones.
RULE 19 P0.0: emergency priority above P0, any agent may send it. Never suppressed, delivered first, the lead agent is copied, always include why=. Capped per sender per hour; over the cap it is demoted to P0. Full review within 24h.
